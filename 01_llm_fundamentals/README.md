# 01 — LLM Fundamentals

## Objectives

Build an intuitive and mathematical understanding of how language models represent text, learn patterns, and generate tokens.

## Concepts to understand

- Tokenization strategies, vocabulary, and token limits
- Embeddings and semantic similarity
- Transformer blocks, self-attention, and positional information
- Next-token prediction, inference, and context windows
- Prompt design and generation controls such as temperature, top-k, and top-p
- Differences between commercial APIs and open-weight models

## Planned implementations

- Inspect tokenization and compare token counts across text samples.
- Calculate embedding similarity and visualize simple examples.
- Work through attention and transformer calculations with small inputs.
- Compare prompt variations and decoding settings with documented observations.
- Run a small API or open-weight inference example when its dependencies and credentials are configured.

## Relevant technologies

Python, Jupyter, NumPy, Matplotlib, tokenizer libraries, provider APIs, and Hugging Face tooling where appropriate.

## Suggested progression

1. Explore text tokenization and context limits.
2. Study embeddings and similarity.
3. Derive and visualize self-attention.
4. Experiment with prompting and decoding.
5. Compare model/API behavior and document cost, latency, and quality.
